## Finding

The source title declares a 999-point blueprint, but the source text does not contain 999 individually numbered bullet records.

A programmatic extraction of the complete 1,231-line source identified:

- **999** declared conceptual points by title/framework.
- **391** explicit numbered bullet entries (`* N. ...`) with unique point numbers.
- **608** point numbers are not present as individually numbered bullet records.
- The source also contains section ranges, grouped point references, prose concepts and visual-analysis code that are not equivalent to individual numbered points.

Therefore:

> **391 explicit point records have been indexed. The remaining 608 are not being invented or inferred.**

## Why this matters

A truthful implementation program cannot manufacture missing source requirements.

For the remaining material, the correct process is:

1. Preserve the source section/range.
2. Extract grouped concepts separately.
3. Map each grouped concept to the current platform.
4. Mark it PRODUCTION / R&D / LORE / DECISION REQUIRED / PROHIBITED_OR_REDESIGN.
5. Only create a discrete requirement when the source actually provides a discrete requirement.
6. Never use the number 999 as evidence that 999 capabilities exist.
