SETTINGS ARCHITECTURE
BACKGROUND PERSISTENCE
The void background color is stored in localStorage and synced to your profiles table (bg_color column). On every page load, bg.js reads localStorage first. If not found, it falls back to the profile's stored color. Custom hex colors are fully supported alongside the 8 preset void palettes.
APPEARANCE ENGINE
The appearance system (OmegaAppearance) applies CSS variable overrides for background, text color, and font family. Settings persist in localStorage. Font options affect the body font-family via CSS custom property override. Resetting clears all localStorage keys and reloads the page to restore omega-ui defaults.
LANGUAGE SYSTEM
Language selection stores the locale code in localStorage under 'omega_lang'. The platform reads this key at boot to apply RTL layout for Arabic (ar), and locale-appropriate date/number formatting. Adding new languages requires a translation object in the i18n module loaded by bg.js.
ACCOUNT OPERATIONS
Deactivate calls the deactivate_account() RPC which suspends access_approved without deleting data. Delete calls delete_account() which triggers GDPR erasure — all profile data, achievements, task records, and the auth user are permanently removed. Neither operation can be performed with a privileged backend key from client code.
