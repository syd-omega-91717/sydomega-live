# Ω React Evolution

## Strategy
SYD OMEGA remains progressively compatible with its existing framework-free surface while React becomes the component architecture for new high-interaction experiences.

## First React surface
- Mission Workspace
- capability search
- responsive module cards
- keyboard/focus-safe interaction
- runtime evidence and provenance bridge

## Migration rule
Do not rewrite stable legacy pages blindly. New complex interfaces should be componentized in React first, then integrated through the existing runtime bridge. Preserve URLs, accessibility, data contracts and governed execution.

## Quality gates
1. Build must remain deterministic.
2. No secrets in client code.
3. Every state-changing agent action requires evidence and appropriate review.
4. Existing functionality must not regress during migration.
5. React surfaces must remain usable on mobile and desktop.
6. Third-party dependencies are introduced only when they provide material value and have acceptable maintenance/security posture.
