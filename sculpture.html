◆ How to use it
Any page adds one of these with a single attribute — no markup, no wiring, no per-page script:

<div data-omega-sculpture="signet"></div>

signet · agents · matrix · gates · elements · ascension

One WebGL context serves every mount on a page, and only marks actually on screen are ever drawn. Where motion is not wanted — a member with prefers-reduced-motion set — each mark composes a single still frame instead of a loop; where WebGL is unavailable entirely it falls back to the same composition drawn flat, in the same palette.
