# Ω SYD OMEGA 91717 — Genesis World Cinematic Layer

## Change intent
Add a lightweight, original, responsive cinematic atmosphere to the existing governed World surface without replacing its 3D module map, page contracts, data sources, or runtime architecture.

## Assets
- `assets/omega-genesis-world.svg`: original vector artwork; dark planetary core, Omega sigil, orbital geometry, cyan/gold accents and a small star field.
- `omega-genesis-world.css`: scoped presentation layer for `world.html`; no runtime dependency and no third-party library.

## Truth and authority boundaries
- The SVG is decorative design artwork, not a map of actual infrastructure, satellites, assets, people, telemetry, or financial reserves.
- Live route status, presence, progression, provenance and achievement evidence remain owned by their existing runtime modules.
- Do not bind decorative particles or orbital motion to fake activity.
- Do not use this artwork as proof of ownership, security, deployment or financial state.

## Motion and accessibility
- Orbital motion is slow and restrained.
- The SVG and CSS both respect `prefers-reduced-motion: reduce`.
- The art is a background layer; it does not receive pointer input or hide focus indicators.
- Existing content and module nodes remain in the foreground.
- No external fonts, scripts, APIs or network requests are introduced.

## Performance
- SVG is resolution-independent and locally served.
- The effect uses CSS opacity and SVG transform only.
- No additional canvas, WebGL context, timers, or animation loop is introduced.
- Existing World 3D rendering remains unchanged.
