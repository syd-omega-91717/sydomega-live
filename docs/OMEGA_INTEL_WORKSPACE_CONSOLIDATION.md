# Ω INTEL Workspace Consolidation

`/intel.html` is the canonical user-facing entry point for intelligence discovery.

## Included families
- Intelligence Engine
- Research & Discovery
- Knowledge Loom
- Knowledge Graph
- Graphify
- Graph Explorer / Centrality / Anomalies / Timeline / Evidence / Admin
- Signal Intelligence
- Oracle Prediction
- Pulse
- Nexus
- Codex / Mind Map / Cipher / Atlas

## Non-equivalence rules
The hub does not merge different truth domains:
- Knowledge Loom is provenance-first and source-bound.
- Concept knowledge graphs remain distinct from governed retrieval.
- Prediction/oracle output is probabilistic and is never represented as established fact.
- Signal data remains provider-dependent.
- Graph administration remains governed/admin-only.

## Migration
Specialist routes remain intact. No file is removed merely because the capability is surfaced through the canonical workspace.
