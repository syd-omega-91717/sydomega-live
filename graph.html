GRAPH ARCHITECTURE

D3 FORCE ENGINE
The constellation graph renders via D3 v7 force simulation, loaded dynamically from esm.sh. Five force types: link (distance by type), charge (repulsion by node type), center (gravity), collision (size-aware). Draggable nodes.
NODE HIERARCHY
Four node types: ELEMENT (largest, 28px, glowing), GOD (22px, glowing), SIGN (14px, element-coloured), MEMBER (6–17px, authority-scaled). Links: sign→element, sign→god, member→sign.
MEMBER DATA
Member nodes are sourced from profiles where access_approved=true. Node size scales with gate number (auth → gate → radius). Only public profile fields are used (display_name, sign, axis_a/b/c).
SVG RENDERING
Graph renders as inline SVG inside the page. Zoom: D3 zoom (scale 0.2–4×). Pan: drag anywhere on SVG canvas. Glow filter applied to element and god nodes via SVG feGaussianBlur. All labels are SVG text elements.
