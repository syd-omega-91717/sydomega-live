ENTERPRISE ARCHITECTURE
GOVERNMENT SOVEREIGNTY
The Government tier is designed for national-level deployment. Air-gapped means no internet dependency — the platform runs entirely within national infrastructure. National data sovereignty means all data stays within the country's borders. Legislative compliance packages cover GDPR, PDPA, NDMO, and custom national frameworks.
API LICENSING MODEL
API access is metered by tier. Starter has no API access. Professional gets 60 requests per minute. Enterprise gets unlimited. API keys are managed in the api_keys table. Each key carries a type (read, write, admin) and a request counter. Rate limiting is enforced at the edge layer before any database query.
WHITE LABEL PROTOCOL
Enterprise tier clients can deploy under a custom domain with their own branding. The white label removes Ω branding from the UI while retaining the full platform capability. Custom domains use Vercel's domain alias system. The sovereign authority system, matrix, and agent infrastructure are identical across all branded deployments.
REVENUE INTELLIGENCE
The revenue dashboard reads from the enterprise_accounts table via a get_enterprise_summary RPC that aggregates MRR, active accounts, total seats, and government account count. It is owner-only: the RLS policy on enterprise_accounts restricts all rows to platform_owners. No member can access another member's enterprise data.
