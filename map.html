MAP ARCHITECTURE

LEAFLET ENGINE
Map renders via Leaflet 1.9 loaded dynamically from esm.sh. Tile layer uses OpenStreetMap. Markers are custom SVG elements coloured by elemental alignment. No external map API keys required.
PRIVACY MODEL
Member coordinates are stored at city granularity only. Exact locations are never collected. The public:true flag on profiles controls whether a member appears on the map at all.
LAYER SYSTEM
Two toggleable layers: MEMBERS (all public-profile sovereigns by element colour) and NODES (strategic platform anchor points). Each layer is independently togglable without map reload.
DATA SOURCE
Member pins sourced from the profiles table where is_public=true and lat/lon are set. Nodes sourced from the map_nodes table if present, else hardcoded to strategic capitals.
