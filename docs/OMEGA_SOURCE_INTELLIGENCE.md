## Adoption rule

SYD OMEGA does not blindly copy repositories. Candidate ideas enter an evidence queue, are evaluated for license compatibility, maintenance health, security posture, performance, browser compatibility, and architectural fit, then are either rejected, referenced, adapted, or integrated with explicit provenance.
