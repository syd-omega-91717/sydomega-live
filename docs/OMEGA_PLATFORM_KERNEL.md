# Ω SYD OMEGA 91717 — Platform Kernel

The Platform Kernel is the shared contract for turning many surfaces into one observable platform.

## Layers

Experience → Platform Services → Intelligence Fabric → Data Plane → Trust & Control → Economy

## Capability lifecycle

SPECIFIED → IMPLEMENTED → TESTED → RUNTIME VERIFIED → PRODUCTION VERIFIED → OBSERVED → SCALED

BLOCKED is explicit and is never silently treated as healthy.

## Rules

1. Every capability has one stable ID and one canonical product route.
2. A route becomes observed only after a browser probe succeeds.
3. Missing data is missing; it is never replaced with zero.
4. Presentation never fabricates metrics.
5. Browser-shipped code cannot prove backend health.
6. Production verification requires deployment evidence and remains separate from local/browser checks.
7. New platform modules register here before becoming another isolated subsystem.

This kernel complements the existing capability registry, object graph, evidence graph, control surfaces, agent operations, commerce and governance contracts without forcing a frontend rewrite.
