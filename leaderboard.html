LEADERBOARD ARCHITECTURE
AUTHORITY FORMULA
AUTH = sqrt(A³+B³+C³) × φ/e where φ=1.6180339887 (Golden Ratio) and e=2.7182818285 (Euler's number). The cubic weighting rewards high concentration in a single axis more than moderate scores across all three. Apex score of 27.8367 achieved at A=B=C=9.
RANKING PIPELINE
Three-tier fallback: (1) rankings edge function for server-computed AUTH; (2) leaderboard_snapshots table for daily snapshot data; (3) live profiles query with client-side AUTH computation. This ensures the leaderboard always renders regardless of edge function availability.
SNAPSHOT CADENCE
Daily snapshots prevent real-time rank manipulation and gaming. Scores are calculated server-side at midnight UTC and written to the leaderboard_snapshots table. This mirrors Google PageRank's batch computation philosophy: authority is earned over time, not gamed in the moment.
INTEREST GRAPH
The leaderboard is weighted by interest-graph authority: members who contribute knowledge, master skills, and build contributions earn higher axis values. The Sovereign Order values demonstrated competence over social metrics. No follower count, no engagement farming — only sovereign merit.
