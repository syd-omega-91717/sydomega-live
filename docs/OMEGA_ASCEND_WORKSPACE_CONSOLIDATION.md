# Ω ASCEND Workspace Consolidation

The canonical user-facing ASCEND destination is `/ascend.html`.

It groups the existing learning and progression family without deleting specialist routes:
- Academy
- Courses
- Deep Work
- Contributions
- Evolution
- Levels
- Phases
- Ascension
- Domain Mastery

The hub is an information-architecture layer. It does not become authoritative for member progression; existing backend/data contracts remain authoritative on specialist surfaces.

## Truth boundaries
- Authority and axis state: backend/member state where available.
- Focus/deep-work activity: user activity.
- Levels/phases/ascension: progression model.
- Lore/presentation: never promoted to achievement evidence.

## Migration rule
Specialist routes remain deep-linkable until their capability is fully absorbed, tested, authorized, instrumented and verified in production.
