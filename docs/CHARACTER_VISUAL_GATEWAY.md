# Character Visual Gateway

The character gateway is an additive presentation layer over the canonical identity system.

## Source of truth
- Character framework: `OMEGA_PAGE_CHARACTER_FRAMEWORK.md`
- Archetype manifest: `config/page-character-manifest.json`
- Functional character sheet: `character.html`
- Profile/genealogy: `profile.html`
- Bloodline: `bloodline.html`
- Canonical cinematic layer: `omega-cinematic-system.js`

## Implemented surface
- Observatory, Arena, Studio and Archive archetypes are represented visually.
- Existing functional destinations remain authoritative.
- The gateway adds no WebGL renderer.
- Reduced-motion and keyboard focus behavior are included.
- The visual system uses the existing Omega design tokens and cinematic layer.
