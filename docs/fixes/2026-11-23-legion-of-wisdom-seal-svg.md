### Legion of Wisdom seal as an original vector asset (2026-11-23)

**Why.** The owner's ecosystem brief names a "Legion of Wisdom" certification stamp. The only artwork for it was AI-generated raster concept art (`assets/concept/medallion-01-*.webp`, recorded `unreviewed`/baseline) with garbled ring text, and a second render supplied 2026-11-23 carrying a Gemini watermark. A raster of unknown provenance is a weak base for a seal meant to anchor "defensive trademarking", and the media-rights gate (`scripts/media-rights-gate.py`) refuses a new image with no record.

**Fix.** `assets/omega-legion-of-wisdom-seal.svg` (7 KB, 600x600): a gold ring with arc text "THE 144,000 UNIFIED CONSCIOUSNESS GRID" / "LEGION OF WISDOM", an onyx field, nine blue stars, a faceted winged lion (one drawn half and one drawn wing, mirrored with `<use>`), a geometric Omega (stroked path, no font), "SYD OMEGA . 91717". Every shape is authored in the file; the supplied concept render was a composition reference only, nothing traced or copied. Rights record added to `docs/media-rights.json` (`owner-generated`, with an explicit note that copyright in purely AI-authored artwork is jurisdiction-dependent and not asserted). Shown on `design-lab.html` beside the existing concept medallion. NOT wired to anything that awards it.

**Alive, with no JavaScript.** The seal animates itself from a `<style>` inside the SVG, so it works as a plain `<img>` on any page: the wings beat (rotating about each shoulder, 5.2 s cycle, mirrored), the nine stars twinkle on staggered delays, the eyes ease. Every animation sits inside `@media (prefers-reduced-motion:no-preference)`; ring text never moves. `scripts/verify-legion-seal.js` (6/6) compares the same `<img>` half a cycle apart: wing and star regions change, ring text does not, and under reduced motion every region is pixel-identical. Note for anyone testing this: an SVG used as `<img>` is its own document, so Playwright's `reducedMotion` emulation does NOT reach it (the first run showed the seal still moving and would have failed a correct file); the test launches Chromium with the real `--force-prefers-reduced-motion` switch. Viewed at the peak of the beat: wings lift and stay attached to the mane.

**Verified.** XML well-formed; rendered in Chromium at 600, 160, 64 and 32 px (recognisable as a gold seal at 64; ring text is legible from about 160 px up). Found and fixed two defects by looking at the render: the Omega's legs curved inward into a V instead of flaring to serif feet, and its arch collided with the lion's chin. `design-lab.html` rendered signed-in (Supabase stubbed) on desktop 1280 and mobile 375: image loaded, no horizontal overflow, 0 page errors. `media-rights-gate.py` passes with the record (534 files, 2 with records) and fails without it (checked both ways).

**Also in this change: the Zero-Point intro hand-off and its test.** `ci-local.sh` failed `skip: Enter ends the intro within 1.5 s` after passing several times; instrumenting it (60 sequential runs clean; 4 parallel runs of 25 failed dozens of times) showed two separate things. (1) A real product gap: bg.js ended the legacy intro on a fixed 3.1 s timer even when the Zero-Point module was still downloading, so under load (a slow phone or network) the visitor silently got the old intro. Fixed in `bg.js`: while the module's fetch is pending (`window.__omegaZPPending`, cleared on load and on error) the legacy timer waits for it, with a 6.5 s hard ceiling, and a held (upgraded) intro still ends itself. (2) Test design: wall-clock budgets (the designed fade alone is 0.82 s) and checks that needed the live 4.6 s overlay cannot hold on a starved machine. Rewritten without weakening what is proved: a `pause()` hook plus a MutationObserver that pauses at the first moment the canvas exists removes the race with the intro clock; a skip is proved causally (a held intro has no timer that can end it, so if it ends after the key press the key ended it); the legacy-fallback check reads a lifecycle recorder instead of catching the overlay mid-air; natural completion claims only "ended with no input" because under starvation the 5.5 s safety timer may legitimately win. `pause()` clears the safety timer but leaves the key and click handlers, so a visitor can never be stuck behind a paused intro (a static test pins that). Result: `verify-zero-point-intro.js` 29/29 alone and 29/29 in each of 6 parallel runs (the load that failed every earlier version); `scripts/tests` 2094 OK.

**Not done / not verified.** (1) Ring text uses `Cinzel, Georgia, serif`; an SVG used as `<img>` cannot load webfonts, so it renders in the fallback serif everywhere it is used that way. Outlining the text would fix it but needs a font file that is not in the repo. (2) Not wired as an awarded stamp: nothing in the repo defines what earns the Legion of Wisdom stamp (`passport.html` stamps are free-form localStorage entries), so awarding it would be invented behaviour. (3) The seal is a stylised homage to the supplied render, not a copy, so it differs from the owner's reference (no red triangle, no rune-stone plinth). (4) Not a registered mark; no trademark or copyright clearance is claimed. (5) Not deployed.
