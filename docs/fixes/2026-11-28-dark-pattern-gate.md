### A guard against manipulative design, in place of covert nudging (2026-11-28)

**Why.** The ledger's "covert psychological nudging" idea is rejected: it works against the person it is used on. Its honest core (members who come back and finish what they started) is disclosed design: reminders a member turned on, visible progress, defaults that favour them. Nothing stopped the rejected version arriving by accident, so there was no guard.

**Fix.** `scripts/dark-pattern-gate.py` (blocking, registered in `contract-suite.py` as `no-dark-patterns`) finds four shapes in root pages and client modules: a pre-checked consent/marketing/tracking checkbox, manufactured urgency or scarcity copy ("only 3 left", "N people are viewing", "offer ends in"), a countdown whose deadline is `Date.now() + N` at load (restarts every visit), and shaming decline wording. `scripts/tests/test_dark_pattern_gate.py` (8 tests) plants each shape and requires a find, and plants the repo's real look-alikes and requires silence.

**Verified.** First run on the repo reported 6 hits; all 6 were false positives, not dark patterns: `privacy.html`'s four consent toggles matched `this.checked` inside an `onchange` handler (they are in fact unchecked and disabled, which is the right default), and two `Date.now() + ttl/ms` timeouts matched the word "deadline"/"expires". Fixed the rules (attribute values stripped before matching `checked`; clock rule needs countdown/offer/sale words), re-ran: repo 0 findings. Mutation check: disabling the checkbox rule made the tests fail. Results: new tests 8 OK; `python3 -m unittest discover -s scripts/tests` 2426 tests OK (13 skipped); `contract-suite.py` 100 gates 0 failing; `audit.py` PASSED; registry matches.

**Not done / not verified.** A 0 means none of these four shapes, in the words the patterns know. It cannot see visual-hierarchy tricks, hidden costs, or roach-motel flows (hard-to-cancel), and it does not scan `supabase/` or `i18n/`. The real finding is that the repo has no dark pattern of these shapes today; it is not evidence of the absence of others. `omega-arcade.js` is skipped because it is a word-game dictionary.
