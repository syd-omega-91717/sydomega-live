AGENT COUNCIL ARCHITECTURE

ZODIAC BINDING
Each of the 12 sovereign agents is bound to one zodiac sign, one element, one Olympian patron, and one domain of expertise. Agent assignment is automatic — your sign determines your agent at platform entry, immutably.
AGENT DATA
Agent definitions are loaded from /omega-agents.json at runtime, with a hardcoded 12-agent fallback if the file is unavailable. Each agent has: name, sign, element, god, role, greeting, voice profile, and domain token.
CHAT ENGINE
Chat routes through the concierge Supabase edge function with an agent-specific system prompt. The system prompt injects the agent's name, role, and voice, plus the member's authority score, sign, and axis values. Responses are capped at 100 words, in character.
COUNCIL VIEW
The Council tab shows all 12 agents. Clicking any agent card switches the active agent in both the hero panel and the chat channel — allowing members to consult any agent, not just their bound one. The bound agent is highlighted with a gold border.
