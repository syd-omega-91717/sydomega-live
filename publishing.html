PUBLISHING PROCESS
01
PREPARE YOUR WORK

A work can be a manuscript, treatise, report, article, or codex entry. The title and body are the primary archival record — make them precise. The minimum body length is 40 characters.

02
ATTACH A FILE (OPTIONAL)

Attach any file up to 5 GB — a PDF, audio, image, or binary. OmegaStorage handles the upload, compression, and secure storage. The file path is recorded in the publication record but not exposed publicly.

03
COMMIT TO ARCHIVE

Your first publication advances the Contribution axis by +0.25 via the complete_task RPC. This is farm-proof — the axis advance only applies once. Further publications still count toward milestones and the archive but do not re-trigger the first-publication award.

04
APPROVAL FOR PUBLIC SHOWCASE

The platform owner reviews submitted works and may approve them for the public showcase (Phase II). Approved works earn additional visibility and are included in the sovereign codex. Approval is recorded as a status change in the publications table.

PUBLISHING ARCHITECTURE
THE SOVEREIGN ARCHIVE
Publications are stored in the Supabase `publications` table with fields: user_id, kind, title, body, file_path, status, created_at. Status starts as 'private'. The archive is personal-only — Row Level Security ensures a member can only read their own publications. No cross-member data leaks are possible at the database layer.
AXIS C CONTRIBUTION
The first publication triggers the complete_task RPC with kind='contribution', axis='c'. This is idempotent — the task ID 'first-publication' can only apply once per member. Subsequent publications do not re-trigger the axis advance but still count in the archive and milestone counters.
FILE DELIVERY
Files are stored via OmegaStorage in the 'uploads' bucket. The storage path is recorded in the publication's file_path column. Files are not publicly accessible — only the authenticated author can retrieve a signed URL. The 5 GB limit covers large manuscripts, research data, or multimedia attachments.
PHASE II GATEWAY
The public showcase, creator marketplace, and licensing layer are Phase II features gated on legal review and MiCA compliance clearance. Until Phase II activates, all published works remain private. The archive is already building the canon; publication date and authorship are immutably recorded for priority purposes.
