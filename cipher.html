CIPHER ARCHITECTURE

ELEMENT-SCALE CIPHER
The Sovereign Cipher uses musical scale semitone offsets as substitution keys. Each of the 9 elements has a unique scale pattern. The cipher rotates through scale positions to encode each character, producing a different substitution alphabet per element.

WAVEFORM VISUALISER
The waveform below the ciphered output visualises the encoded character stream as a frequency wave. Each character's Unicode value modulates the wave amplitude using the element's scale pattern — the cipher made visible as sound.
ENTROPY METRIC
Shannon entropy measures the information density of the plaintext. Higher entropy means more unpredictable content, which typically ciphers into stronger encoded output. The Void key (scale [0,7,12]) produces the most compressed cipher alphabet — fewest substitution options, maximum pattern repetition.
