PLATFORM ARCHITECTURE
18 MODULES, ONE ORGANISM
The platform is not a collection of features. It is 18 interdependent modules forming a single sovereign organism. Each module has a designated ID (M1–M18), a color code, and a set of pages. Every page belongs to exactly one module, and every module connects to at least two others.
THREE RINGS OF SOVEREIGNTY
The ecosystem map is arranged in three concentric rings. The inner ring holds the core (Ω). The middle ring holds the primary modules (identity, ascension, media, economy). The outer ring holds the extended modules (heritage, intelligence, legal, elemental). Rings reflect dependency depth, not importance.
MODULE INTERDEPENDENCY
M1 (Platform Core) is the root — all modules depend on it for auth. M12 (Progress Engine) is the central value layer — it receives signals from M3 (Gaming), M4 (Achievements), M8 (Communication), and M11 (Heritage). M17 (Intelligence) reads from all modules. No module is isolated.
196-PAGE PLATFORM
The full platform comprises 202 pages mapped across 18 modules. Each page is a self-contained HTML/JS application that communicates with Supabase via the publishable API key. All inter-page data sharing happens through the profiles table, shared localStorage keys, and the Omega progress engine.
