### Franchise slate: seven planned franchises, shown as concepts (2026-11-06)

**Why.** The owner asked to start building the films, series and games. The founder's list names seven franchises (22 planned films, paired with seven game concepts); only two of the titles (Myth of the Stones, Wrath of the Gods) appeared in `media.html`, and the repo's own creative canon is a different set (12 Olympian-themed films F01-F12, "Cave of the Shadows", "Babylon Singularity" and others). The repo holds no scripts, footage or playable builds for the seven, and `docs/fixes` for #1165 already reclassified unsupported product claims as concepts, so the slate has to say CONCEPT.

**Fix.** New `config/omega-franchise-slate.json` is the one source: seven franchises, `filmsPlanned` (5, 3, 1, 5, 3, 3, 2 = 22), a game concept each, `status: CONCEPT`, an empty `evidence` list, and the founder's Zodiac Wars pitch. `universe.html` gets a SLATE tab rendering the same seven cards in the existing `.media-card` style, with an intro that states every title is a concept and every count a plan, and a link to `/media` (the separate Olympian slate) and `/factions` (the Celestial Knights). The disclaimer and the status lines carry `data-no-clamp` so the platform's read-more clamp cannot hide them on a phone (it did, in the first render). `scripts/tests/test_franchise_slate.py` fails if the page and the JSON drift, if a non-CONCEPT status has no evidence, or if the panel makes an availability claim (released, streaming, playable, in production) while every title is a concept.

**Verified.** Render, signed-in stub, `universe.html`, SLATE tab clicked like a user: desktop 1280 px and phone 375 px both show 7 of 7 cards, horizontal overflow 0, 0 page errors, every status `CONCEPT`. Unit tests 1154 OK (including the CSP inline-handler ratchet, which caught a first draft that used an inline `onclick`; the SLATE button now uses an event listener) and `production-contract.py`, which failed CI on the first push because the two new links were written `/media` and `/factions` (it requires local links to resolve to a file: `/media.html`, `/factions.html`); `ci-local.sh` 34 of 35 blocking checks pass, the 35th ("2v PR-workflow gates") needs the `public/` build CI produces and was not runnable here; `check-inline-js.py`, `i18n-contract.py`, `brand-glyph-check.py`, `page-count-claims.py`, `audit.py` (0 critical), `module-contract.py`, `omega-registry.py --check`, `context-budget.py`, `reachability-contract.py` and `verify-runtime.js` (13 pages) pass.

**Not done / not verified.** No scripts, trailers, game builds, release dates or per-title lore pages were created, because none exist to show. The two canons (this slate and the 12-film Olympian slate on `media.html`) are not reconciled: that is the owner's content decision. The slate text is English only; the SLATE tab label has no `data-i18n` key, matching the other tabs on the page. The founder's earlier claims about complete production scripts were not verifiable in the repo and are not repeated.
