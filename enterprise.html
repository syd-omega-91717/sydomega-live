ENTERPRISE ARCHITECTURE
GOVERNMENT SOVEREIGNTY
Sovereign deployment is an architectural objective, not a verified capability claim. Air-gapped operation requires a separately tested deployment and offline dependency inventory. Data residency and legislative compliance must be assessed and contracted per jurisdiction.
API LICENSING MODEL
API keys are inventoried with scopes, activation state, optional expiry, and last-used metadata. Published quotas are not active until gateway enforcement is implemented and validated; limits must be agreed per tier and capacity. Secret values are not rendered in this dashboard.
WHITE LABEL PROTOCOL
White-label and custom-domain deployments require a validated hosting configuration and a signed scope. Do not promise Vercel alias setup or equivalent isolated infrastructure until the provider path and deployment have been verified.
REVENUE INTELLIGENCE
The revenue dashboard reads from the enterprise_accounts table via a get_enterprise_summary RPC that aggregates MRR, active accounts, total seats, and government account count. It is owner-only: the RLS policy on enterprise_accounts restricts all rows to platform_owners. No member can access another member's enterprise data.
