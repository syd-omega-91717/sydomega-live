GDPR Art. 25 mandates privacy-by-design. All features built consent-first. Default is privacy-on, not privacy-off.
DATA MINIMISATION
Only data necessary for platform function is collected. No third-party trackers. No advertising infrastructure.
SOVEREIGN PRIVACY ARCHITECTURE
ROW-LEVEL SECURITY
Every table in the Supabase database has RLS (Row-Level Security) policies enforced at the database layer. No matter what API call is made from the client, a user can only read or write their own data. Platform owners have elevated access enforced by the platform_owners table, not the profiles table, to prevent infinite recursion.
CONSENT AS SOVEREIGN ACT
Consent is not a checkbox buried in a terms page. It is a first-class data structure stored in the consent_records table with timestamps, versions, and revocation records. Every consent state is auditable. You can revoke any consent at any time and it takes effect immediately.
DATA PORTABILITY (ART. 20)
Your data is yours. The export function collects your profile, axis values, task completions, journey logs, consent records, and all sovereign metadata into a portable JSON file. You can take your data and leave at any time. The platform does not create data lock-in.
THE ERASURE PROTOCOL
GDPR Article 17 grants the right to erasure. The request_account_erasure RPC creates an erasure record and queues a 30-day deletion job. The platform sends a confirmation email. After 30 days, all personal data is permanently and irreversibly deleted from the database and all backups within the retention window.
