FORGETTING CURVE
Ebbinghaus (1885) showed memory decays exponentially without reinforcement. Within 24h, ~50% is forgotten; within a week, ~70%. Regular review (spaced repetition) anchors memories in long-term storage by exploiting the spacing effect.
Ebbinghaus, H. (1885). Über das Gedächtnis
GENERATION EFFECT
Slamecka & Graf (1978): material that you generate yourself (write, elaborate, explain) is remembered significantly better than passively read material. Writing notes forces generative encoding — the act of capturing knowledge deepens it.
Slamecka & Graf (1978). Journal of Experimental Psychology
ELABORATIVE INTERROGATION
Asking "why?" and "how?" while note-taking forces deeper semantic processing (Craik & Lockhart, 1972, levels of processing). Notes that include explanations, examples, and connections are recalled 40–50% better than verbatim copies.
Craik & Lockhart (1972). Journal of Verbal Learning
ZETTELKASTEN METHOD
Luhmann's slip-box system (1960s–2000s): notes linked by ideas, not folder hierarchy, build an external scaffold for thought. Over 30 years, Luhmann produced 90,000 linked notes and 58 books. Tags and bidirectional links simulate this for digital PKM.
Luhmann, N. (1992). Zettelkasten — Kommunikation mit dem Zettelkasten
WORKING MEMORY OFFLOADING
Cognitive load theory (Sweller, 1988): working memory holds ~4 chunks simultaneously. Externalizing notes frees working memory for higher-order reasoning. GTD (Allen, 2001) systematizes this: capture everything external so the mind can think, not hold.
Sweller (1988) · Allen (2001). Getting Things Done
PROGRESSIVE SUMMARIZATION
Forte (2017) proposes layering highlights: original → bold → highlight → summary. Each pass forces you to identify signal vs. noise. The final distillate is highly actionable. The key is that each layer is built incrementally, not in a single session.
Forte, T. (2017). Progressive Summarization, Praxis Blog
