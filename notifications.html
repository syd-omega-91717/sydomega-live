NOTIFICATION CATEGORIES
NOTIFICATION SCIENCE
01
INTERRUPTION COST
Gloria Mark (UC Irvine): after a digital interruption, it takes an average of 23 minutes 15 seconds to return to a task at full focus. The sovereign manages notifications surgically — batched, timed, controlled — never reactive.
02
ZEIGARNIK EFFECT
Unfinished tasks occupy working memory disproportionately — the Zeigarnik effect. Reminders with clear completion states reduce this cognitive load by externalizing the task, freeing mental RAM for higher-order thinking.
03
TIME-SENSITIVE PRIORITY
Eisenhower Matrix: urgent+important (do now), important+not urgent (schedule), urgent+not important (delegate), neither (eliminate). Notification priority encodes this matrix — only critical alerts interrupt deep work.
04
PROSPECTIVE MEMORY
Prospective memory — remembering to do something in the future — is cognitively expensive and error-prone. External reminders reduce failure rates by 60-80% (Marsh et al., 1998). The sovereign outsources prospective memory to systems.
05
NOTIFICATION BATCHING
Cal Newport advocates notification batching: process communications at fixed times (e.g., 9am, 1pm, 5pm) rather than reactively. Research shows this reduces daily context switches by 40%, significantly improving deep work throughput.
06
SOVEREIGN INFORMATION DIET
The sovereign treats information like nutrition: caloric density matters. A single high-signal notification per hour outperforms a firehose of low-signal noise. Curated inboxes, like curated diets, optimize for performance.
