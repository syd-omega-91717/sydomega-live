AUTOMATION ENGINE — ARCHITECTURE
HOW THE ENGINE WORKS

The Automation Engine is a sovereign rule interpreter that evaluates trigger conditions against platform events in real time. When a condition is satisfied, the corresponding action chain executes silently — no manual intervention required.

Rules are evaluated in priority order: SYSTEM rules (enforced globally) fire before MEMBER rules (user-defined). The engine uses a dedicated automation_rules table to persist user overrides and custom rule definitions.
