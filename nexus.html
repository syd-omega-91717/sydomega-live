NEXUS ARCHITECTURE

FORCE-DIRECTED GRAPH
The Nexus renders all approved sovereigns as nodes in a live force-directed graph. Repulsion keeps nodes separated; attraction links element-aligned members. The simulation runs on raw canvas — no external libraries. Physics settles after 200 frames.
NODE SIZE & COLOUR
Node radius scales with authority score (AUTH ÷ APEX × 16px). Colour maps to element alignment derived from zodiac sign. Your node is highlighted with a gold ring and pulse animation to always identify you in the graph.
EDGE FORMATION
Edges form between nodes sharing the same element (35% probability) or adjacent gate levels (8% probability). This creates element clusters — Fire nodes cluster together, Void nodes cluster apart. Network density reflects community coherence.
LIVE UPDATES
A Supabase Realtime subscription listens to profile changes. When a sovereign's authority updates, the change appears in the live activity feed at the bottom of the graph. The graph structure updates on next page load.
