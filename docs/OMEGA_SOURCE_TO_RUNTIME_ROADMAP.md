# Ω Source → Runtime Roadmap

This is the execution order for converting the source corpus into verified platform capability.

## Wave 1 — Provenance

- Keep the five-source registry canonical.
- Keep the 999/391/608 accounting explicit.
- Attach source identifiers to future architecture decisions.
- Never represent an unlocated source statement as an explicit numbered point.

## Wave 2 — Capability mapping

Map every grouped source requirement into one of:

- existing production capability;
- partial capability;
- design proposal;
- simulation/lore;
- blocked external dependency;
- unverified production capability.

## Wave 3 — Runtime binding

For each production candidate, bind:

source → capability → authorization → action → event → evidence → verification → deployment

## Wave 4 — High-value production gaps

Prioritize the existing gaps that repeatedly appear in the source corpus:

1. authentication hardening and MFA evidence;
2. leaked-password protection;
3. semantic RLS regression coverage;
4. payment checkout/webhook/entitlement proof;
5. storage isolation proof;
6. backup/restore exercise;
7. production smoke evidence;
8. mobile critical journeys;
9. accessibility and performance gates;
10. AI provenance and permission evaluation;
11. external notification verification;
12. current Edge Function source/live reconciliation;
13. Vercel deployment/integration health.

## Wave 5 — Civilization runtime

The civilization atlas should progress in this order:

city → district → building → service → capability → mission → task → event → evidence → verification → progression → credential

The current atlas seed is intentionally simulated where authoritative production data does not yet exist.

## Wave 6 — Advanced spatial layer

Only after the object model and runtime contracts are stable:

- OGC 3D Tiles for scalable streamed 3D content;
- CityGML/CityJSON-compatible semantic city data;
- OGC API - Tiles for standardized tile access;
- dynamic event/evidence overlays;
- time-aware city state.

The spatial layer must remain a renderer of governed state, never the source of authoritative state.
