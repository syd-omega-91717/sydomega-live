SIGIL ARCHITECTURE

OmegaSigil ENGINE
The sigil renderer is a standalone SVG generator (window.OmegaSigil). It derives glyph geometry from the sovereign identity hash, element alignment, authority score, and complexity level. Each sovereign gets a unique, mathematically derived symbol.
VARIANT SYSTEM
Six visual variants: STANDARD, INVERSE, MONO, NEON, GHOST, and MINIMAL. Each variant applies a different rendering pass over the base sigil geometry — same structure, different aesthetic register.
SVG EXPORT
The sigil exports as a clean inline SVG string. Download saves a .svg file. Copy puts the SVG source on the clipboard. The exported sigil is self-contained and renders in any SVG-capable environment.
IDENTITY BINDING
The sigil is bound to the authenticated user's identity hash. Axis overrides (authority, complexity, scale) are cosmetic — the underlying geometry is immutable and unique per sovereign.
