### Agent reels: twelve procedural animatics (2026-11-28)

**Decision.** The owner asked me to think widely, invent what is needed and build "every mentioned subject" for real. I kept one line: the ledger's rejected items (regulator evasion, poisoning other AIs' training data, covert psychological nudging, biometric/DNA locks) stay unbuilt; they are rejected for harm, not for lack of imagination. Everything else I took in an order: first the part I can make real and verify without inventing facts, which is animated reels from the platform's own canon.

**What.** `omega-reels.js` plus a new AGENT REELS tab on `trailers.html`. One 22-second animatic for each of the twelve agents in `omega-agents.json`: generative art in the agent's element (fire embers, water ripples, wind streamlines, metal lattice, sand spiral), the agent's own greeting typed out, its voice words, its five domains, its sign, element and god, and a closing card with where it lives. A bar on every frame reads "PROCEDURAL ANIMATIC · NOT FOOTAGE". Chips pick an agent; play, restart and an exact scrubber. Colour is the canon's (`OmegaEmblem.color(sign)`). Reduced motion gets no autoplay and a composed still.

**Why every word is true.** Every frame is a pure function of the time and a seed from the agent's name, so `scripts/tests/test_reels.py` draws all 12 reels every half second through a recording canvas and fails if any drawn text is not in that agent's record or one of nine fixed labels. Mutation-checked: an invented line is caught; removing the label is caught; truncating the typing is caught; an unchecked `fetch` is caught.

**Choices.** The five motifs are drawn by this file, not by the shared `omega-element-motif.js`: that module is self-driven (one never-cancelled `requestAnimationFrame` loop per mount), so switching agents would leave a loop per switch drawing into a detached canvas. The colour is shared; the look is not, and that is a deliberate departure from CLAUDE.md section 8.1 class 8 (one owner per table), recorded here.

**Verified.** `test_reels` 10 tests OK; `node scripts/verify-reels.js` PASSED 22 of 22 in headless Chromium (the tab is hidden at load and nothing is measured at zero size; after opening it the canvas is 16:9, at the screen's density and painted; twelve chips; each reel differs and its text alternative names the agent, greeting and domains; time changes the picture; it plays; the scrubber seeks exactly; reduced motion; a 390 px phone with no overflow and 44 px targets; a failed fetch of the agent list says so and invents nothing; no page errors). The same script on `main` fails (no tab).

**Bugs found on the way.** (1) `draw()` reset the canvas transform on its first line, which cancelled the page's scale: the frame drew at device-pixel scale and was cropped, so the "not footage" label and the clock fell off the canvas. All 30 earlier checks passed because the Node tests use a fake canvas and the browser checks measured sizes, not pixels. Fixed, and a browser check now requires the label and clock pixels to be lit; with the bug back, that check fails (label 0, clock 0). (2) A re-seed-every-tick mutant passed because purity (same time, same picture) is not smoothness; a continuity test now requires every point drawn to move under 12 px in one 60 Hz tick (clean: at most 2.2 px). (3) The first voice frame drew the greeting across the ring and sign; the ring now fades out before it.

(4) My first tab button used an inline `onclick`, which `csp-inline-ratchet.py` rejects (handlers 4 to 5); the button now carries `data-reels-tab` and `omega-reels.js` wires it with `addEventListener`, calling the page's own `switchTab` at click time. (5) `OMEGA_SKILL_REGISTRY.md` records module size in KB, so it had to be regenerated after the last edit to `omega-reels.js`.

**Not done.** No sound. No reels for the nine elements, the 26 films or the series (those need story the owner has not approved; the agents were chosen because their lines already exist in the canon). A reel for each nav section or feature page is the natural next step. No human has watched them; frame rate on a device is not measured.
