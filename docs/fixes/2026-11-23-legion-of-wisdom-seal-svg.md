### Legion of Wisdom seal as an original vector asset (2026-11-23)

**Why.** The owner's ecosystem brief names a "Legion of Wisdom" certification stamp. The only artwork for it was AI-generated raster concept art (`assets/concept/medallion-01-*.webp`, recorded `unreviewed`/baseline) with garbled ring text, and a second render supplied 2026-11-23 carrying a Gemini watermark. A raster of unknown provenance is a weak base for a seal meant to anchor "defensive trademarking", and the media-rights gate (`scripts/media-rights-gate.py`) refuses a new image with no record.

**Fix.** `assets/omega-legion-of-wisdom-seal.svg` (7 KB, 600x600): a gold ring with arc text "THE 144,000 UNIFIED CONSCIOUSNESS GRID" / "LEGION OF WISDOM", an onyx field, nine blue stars, a faceted winged lion (one drawn half and one drawn wing, mirrored with `<use>`), a geometric Omega (stroked path, no font), "SYD OMEGA . 91717". Every shape is authored in the file; the supplied concept render was a composition reference only, nothing traced or copied. Rights record added to `docs/media-rights.json` (`owner-generated`, with an explicit note that copyright in purely AI-authored artwork is jurisdiction-dependent and not asserted). Shown on `design-lab.html` beside the existing concept medallion. NOT wired to anything that awards it.

**Verified.** XML well-formed; rendered in Chromium at 600, 160, 64 and 32 px (recognisable as a gold seal at 64; ring text is legible from about 160 px up). Found and fixed two defects by looking at the render: the Omega's legs curved inward into a V instead of flaring to serif feet, and its arch collided with the lion's chin. `design-lab.html` rendered signed-in (Supabase stubbed) on desktop 1280 and mobile 375: image loaded, no horizontal overflow, 0 page errors. `media-rights-gate.py` passes with the record (534 files, 2 with records) and fails without it (checked both ways).

**Also in this change: the Zero-Point intro browser test was flaky and is now load-independent.** `ci-local.sh` failed `skip: Enter ends the intro within 1.5 s` on a run that had passed several times before; 1 of 3 isolated reruns failed too. Instrumenting the skip path (60 sequential runs: 0 failures; 4 parallel runs of 25: dozens) showed no logic bug: every overlay was eventually removed with `omega_genesis_seen` set. What failed were wall-clock budgets (the designed fade alone is 0.82 s, measured 0.9-1.45 s end to end) and checks that needed the live 4.6 s overlay on a starved machine. Fixed in the test, not by weakening what it proves: skips are asserted by causation (`OmegaZeroPoint.lastFrame()` well below the 4.6 s duration, so the intro ended early whatever the machine speed); a `pause()` hook plus a MutationObserver that pauses at the first moment the canvas exists removes the race with the intro clock; the legacy-fallback check reads a lifecycle recorder instead of catching the overlay mid-air; the natural-end check claims only "ended with no input", because under starvation the 5.5 s safety timer may legitimately win. `pause()` clears the safety timer but leaves the key and click handlers, so a visitor can never be stuck behind a paused intro. Results are in the Verified list at the end of this entry.

**Not done / not verified.** (1) Ring text uses `Cinzel, Georgia, serif`; an SVG used as `<img>` cannot load webfonts, so it renders in the fallback serif everywhere it is used that way. Outlining the text would fix it but needs a font file that is not in the repo. (2) Not wired as an awarded stamp: nothing in the repo defines what earns the Legion of Wisdom stamp (`passport.html` stamps are free-form localStorage entries), so awarding it would be invented behaviour. (3) The seal is a stylised homage to the supplied render, not a copy, so it differs from the owner's reference (no red triangle, no rune-stone plinth). (4) Not a registered mark; no trademark or copyright clearance is claimed. (5) Not deployed.
