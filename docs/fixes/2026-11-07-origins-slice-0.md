### Studios: Origins Vertical Slice 0, a 3-D browser prototype (2026-11-07)

**Why.** The founder asked for Vertical Slice 0 built to the highest visual standard and in 3-D. The game design document had planned 2-D; the decision was reversed to 3-D on the vendored three.js r160 and the GDD updated to match.

**Fix.** Added `game-origins.html` and five classic scripts (no build step, no CDN, no network calls): `omega-origins-logic.js` (pure rules, UMD so Node can replay them), `-scene.js` (three.js valley, shrine, nine ground rings, boss with nine rings of which two are dark), `-game.js` (loop, input, combat, enemy AI, quest, saves), `-ui.js` (HUD, touch controls, sheets) and `-audio.js` (synthesised sound; the 9.1717 Hz hum is a beat, a 110 Hz carrier amplitude-modulated at 9.1717 Hz). Registered in `nav.js` (PS map plus MEDIA sub-menu), `config/page-cores.json` (media core), `config/page-world-overrides.json` (arena district) and the page-contract bootstrap; `index.html`'s surface count 236 to 237. `scripts/audit-webgl-ownership.py` gained a two-file exemption (`omega-origins-scene.js`, `omega-origins-game.js`) because this page owns one renderer of its own; a test fails if the page ever mounts a sculpture, which keeps one WebGL context per page. Registry game status moved DESIGNED to PROTOTYPE with `build: game-origins.html`; the bible generator now says "Prototype build" instead of "No playable build exists" only when a build is recorded. No reference image was copied; all geometry is primitives built in code.

**Verified.** `node --check` on all five files. Headless Chromium (software WebGL): the page loads with 0 page errors at 1280 and 390 px; no horizontal overflow at 390; touch buttons at least 44 px. A scripted bot played hum, encounter, boss, memory, choice (share) to done in about 70 s of game time at level 4. Save slot round trip restores position and stage; a tampered slot is rejected with "checksum mismatch" and leaves the running state unchanged (the first version of that test was a no-op because the save body is an escaped string, so the corrupt hook was rewritten). `scripts/tests/test_origins_logic.py` (13 tests): level curve, seeded rolls, damage, inventory limit, quest order, save tamper/migration, enemy state machine, no network/payment/CDN strings, status PROTOTYPE. Two defects found and fixed on the way: a fake "Subtitles" option that did nothing, and a reduced-motion toggle that wrote to a property the scene never read.

**Not done / not verified.** No human has played it. Frame rate was measured only under software rendering (about 14 fps), so real-device performance and the 4x-throttle numbers are unmeasured; the slice is therefore PROTOTYPE, not PLAYABLE_SLICE. Art is primitive geometry and far below the mood references. No accessibility audit beyond reduced motion, large text, contrast toggle and real buttons. Audio was never listened to (the headless run mutes it). Page is reachable from the MEDIA menu, labelled "ORIGINS SLICE 0" with a prototype banner; it is not announced as a released game. Multiplayer stays UNAVAILABLE; nothing touches payments, tokens or the database.
