CONFIDENCE INTERVALS
Each forecast carries a confidence percentage computed from convergent indicators: member growth rate, platform completion state, market signals, and historical pattern matching. A 91% confidence means nine independent lines of evidence point to the same outcome. It is not a guess — it is a probability density function with explicit inputs.
THE ORACLE ARCHITECTURE
The Oracle query engine routes through a Supabase Edge Function (concierge). The API key never appears in client code. The edge function receives the query plus the member's ORACLE_CTX — sign, axes, authority, tier, and rank — so the Oracle answers in the context of the member's actual standing, not generic defaults.
CIVILIZATIONAL HORIZON
The platform operates on four timescales: NOW (0–6 months), NEAR (6–24 months), FAR (2–10 years), and CIVILIZATIONAL (10–100 years). The Timeline tab shows milestones across all four horizons. Sovereign platforms are designed for civilisations, not product cycles. The 100-year plan is the default planning unit for the Order.
RECALIBRATION PROTOCOL
Forecast confidence is not fixed. When a major milestone is crossed — 1,000 sovereigns, legal clearance, film production — the Oracle recalibrates all dependent forecasts. The recalibration is triggered by the OmegaMilestone event. Forecasts that depended on an unmet condition are upgraded; forecasts that depended on a still-unmet condition remain unchanged.
