# Ω Legacy Constellation

## Purpose
Expose the repository's original visual source collections inside the live World without treating artwork as live product state.

## Source families
- **Ascension phases:** `BlockChain_Market_Analysis_syd_omega_91717/Phases_syd_omega_91717` — 30 indexed phase assets.
- **Trophy source:** `Trophies_S.Y.D_Omega_91717` — 20 repository image assets.
- **Zodiac signs:** `Zodiac_signs` — 12 zodiac image assets.
- The broader Blockchain Market Analysis collection also contains medals, certificates, identity marks, NFT concepts, mobile/passport concepts and cinematic-game material; those remain source material until separately connected to a governed runtime contract.

## Runtime behavior
The World page renders three lazy-loaded source-asset views:
1. Ascension Phases
2. Trophy Source
3. Zodiac Signs

Each asset is labelled **SOURCE ASSET**. Trophy imagery is explicitly labelled **NOT AN EARNED RECORD**.

## Truth boundary
This component does not create achievements, entitlements, ownership, identity verification, NFT ownership, membership tiers, or live financial state. Those require authenticated, persisted, authorized and tested evidence.

## Evolution path
The source collections can later feed governed achievement definitions, member avatar/identity presentation, phase progression visualizations, collectible metadata, heritage/archive exhibits, and game/arena visual themes—but only after each feature has its own data contract, authorization model, persistence, audit trail and live verification.
