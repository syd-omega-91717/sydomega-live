### Main-character card: one card from the canon and the member's own profile (2026-11-15)

**Why.** The 12 signs are 12 characters in `omega-canon.json` (sign, god, element, agent, house, gate), and `profiles` already records each member's sign and axes. Almost no page reads them from the canon: a scan found about 28 files holding their own hand-typed list of the 12 signs, and only `horoscope.html` references `OmegaCanon`. `character.html` keeps its own SIGNS/GODS/ELEMS arrays (they agree with the canon today, differing only in letter case, so no wrong-god bug) and falls back to `SIGNS[new Date().getMonth()]` for a member with no sign, which invents a character from the calendar (§8.1 class 9). No shared card existed, so each page drew the member's character differently.

**Fix.** New `omega-character-card.js`, mounted by `<div data-omega-character-card>`; `bg.js` injects it only on a page that carries a mount (guard attribute `data-omega-character-card-js`, the module's own identity per §8.1 class 5b). It reads the canon track for the member's recorded sign and the member's own profile columns; read-only, DOM calls only, no write. A missing sign shows "Not set yet" with a link to the profile, never a guessed sign. Empty columns show a dash. Authority is computed by the platform's rule (`sqrt(A^3+B^3+C^3)*phi/e`, canon constants, owner at the canon apex) from the recorded axes, so it matches the page's Authority tile. Mounted on the IDENTITY tab of `character.html`. `scripts/tests/test_character_card.py` pins: no HTML sink or write, no random or calendar value, no copied sign table, columns exist in `live-schema.json`, injection and mount present.

**Verified.** Headless Chromium on `character.html` (stubbed Supabase, signed-in non-owner, axes 3/3/3): card shows Aries / Ares · FIRE · Sentinel / First House / Gate of Ignition, Authority 5.3572 = the page's own tile 5.3572, 0 page errors. A first draft read the stored `authority` column and showed 9.1000 beside the tile's 5.3572 on the same page; that was caught in this render and replaced by the axis rule. Direct renders: no sign, an unknown sign (`Ophiuchus`), empty columns, a string with an `<img onerror>` payload (renders a dash, executes nothing), axes with one null (dash), owner (27.8367, gate 12 of 12). Gates run: audit, module-contract, check-inline-js, xss-sink-ratchet, csp-inline-ratchet, schema-dictionary, silent-failure-detector, omega-registry (regenerated), the new test (6 OK).
