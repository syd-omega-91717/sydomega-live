SOVEREIGN SEARCH ARCHITECTURE
CLIENT-SIDE INDEX
The search index is embedded in the page as a static JavaScript array. No server-side search query is made. This means search is instant (sub-millisecond), works offline, and requires no additional API calls. The index covers all 40+ platform modules.
KEYWORD MATCHING
Each page entry has a keywords string (k) that extends its findability beyond the title. Searching "agents" finds the AI Agents page. Searching "nodes" finds both the Matrix and Games pages. Searching "contract" finds Commissions. The matching is case-insensitive substring search across label, description, and keywords.
OWNER-GATED RESULTS
Certain pages (Approvals, Enterprise Control Panel) are owner-only. These entries are filtered from search results for non-owner members. The filter happens client-side using the is_owner flag loaded at boot. Owner pages are visually marked with a gold left border when they appear.
LOCAL SEARCH HISTORY
Recent visits are stored in localStorage under the key omega_recent_searches. Up to 5 recent pages are remembered per browser session. The history is local-only — it is never sent to the server, never synced across devices, and never stored in Supabase. Clear it by clearing your browser storage.
