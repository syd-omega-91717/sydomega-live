# Ω SYD OMEGA 91717 — Cinematic Visual System

## Design objective
Build a recognizable sovereign visual identity that feels cinematic, intelligent, premium and operational without becoming decorative noise.

## Visual hierarchy
1. Mission / current decision
2. Primary data or action
3. Operational context
4. Secondary navigation
5. System telemetry

## Signature language
- Omega geometry: concentric rings, radial grids and controlled rotation.
- Void field: near-black depth with subtle atmospheric gradients.
- Authority: Omega gold reserved for primary identity, selected states and high-value metrics.
- Intelligence: cyan for live data, links, machine state and evidence paths.
- Risk: crimson reserved for danger, failed controls and destructive actions.
- Glass: translucent surfaces create depth but must preserve text contrast.
- Motion: animation explains state changes, hierarchy or flow. Ambient motion is subordinate.

## Cinematic behavior
- Hero scenes use slow camera-like scale and radial reveal rather than constant movement.
- Cards enter by staggered opacity/translation only when they communicate hierarchy.
- Rotating rings represent system state or progression, not decoration.
- Particle fields represent active telemetry/flow only when a data mapping exists.
- Media surfaces support poster, trailer, playback, continue-watching and recommendation states.
- Gaming surfaces support progression, missions, inventory, achievements, leaderboards and session state.

## Responsive strategy
Desktop: command rail + dominant workspace + inspector/context rail.
Tablet: collapsible navigation + dominant workspace + contextual drawer.
Mobile: bottom/compact navigation + single dominant task + progressive disclosure.

## Accessibility
- No essential information depends on animation, hover, color alone or pointer precision.
- Reduced-motion mode removes continuous rotation and parallax while preserving state.
- Every complex visual has a textual/data fallback.
- Focus states are visible.
- Touch targets remain usable on mobile.

## Performance
- Prefer CSS transforms and opacity for motion.
- Use Canvas/WebGL only where scale or spatial interaction provides real product value.
- Respect `prefers-reduced-motion`.
- Pause offscreen animation with IntersectionObserver.
- Avoid large particle counts on mobile and low-power devices.

## Competitive learning
Netflix: continuity, discovery and content-state persistence.
YouTube: creator/content graph, search and recommendation loops.
PUBG-class games: progression, missions, inventory, social competition and session telemetry.
Enterprise platforms: permissioning, auditability, workflows and operational dashboards.

These are product lessons only. No proprietary visual assets or protected layouts are copied.
