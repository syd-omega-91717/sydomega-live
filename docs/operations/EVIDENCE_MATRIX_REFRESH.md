# Evidence Matrix Refresh

`EVIDENCE_MATRIX.md` is generated by `scripts/evidence-audit.py`. The PR snapshot workflow uploads a review artifact, but it does not modify the committed matrix.

To refresh the committed artifact safely:

1. Create a branch named `automation/evidence-matrix-refresh-YYYYMMDD`.
2. Push a small documentation-only trigger commit to that branch.
3. The `Evidence Matrix Refresh Branch` workflow regenerates `EVIDENCE_MATRIX.md` and commits only that file back to the same branch.
4. Review the generated matrix and open a pull request from the refresh branch to `main`.
5. Merge only after the normal blocking checks pass.

The workflow is restricted to the named automation branch prefix. It never pushes to `main`, never changes source files, and does not run in response to its own bot commit. The generated matrix is an inventory/evidence report; it does not prove that every page feature works or that unresolved canonical page-contract tasks are complete.
