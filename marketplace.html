SOVEREIGN EXCHANGE ARCHITECTURE
THE OMEGA ECONOMY
The marketplace is part of the internal Ω economy. Transactions use Omega tokens — not fiat currencies. All listings are denominated in Ω. The platform takes a 17% commission on each sale (consistent with 91717). The commission is intended to feed the sovereign treasury. The Ω token economy is dormant — it stays off behind platform_settings.tokens_enabled (currently false), so no commission is charged, collected or owed today.
SELLER TIERS
Marketplace access is tier-gated. Free members can browse. Sovereign tier members can list. (Buying isn't built yet — see EARN ON SALE below.) The OmegaCanon.tierUnlocks() function evaluates this at listing time — the tier guard runs entirely in the client against the member's profile.
FILE DELIVERY
File listings are stored in Supabase Storage via OmegaStorage.upload() and the path is recorded in marketplace_listings. There is no purchase step yet, so there's nothing to gate delivery on — this is upload/listing only, not a buy-then-receive flow.
CONTRIBUTION CREDIT
Listing an item in the marketplace earns Contribution XP (axis C). Completing a sale earns additional XP. The marketplace is not just commerce — it is the sovereign economy layer of the contribution axis, recognising economic action as an act of sovereignty.
LISTING PROCESS
01
PREPARE YOUR WORK

A listing can be a document, report, service, code, or any sovereign creation. Title and description are the primary discovery mechanism — make them precise.

02
SET YOUR PRICE

Price in Omega tokens. Set to 0 for a free listing. Free listings still contribute to your Contribution axis. All prices are visible to all members.

03
UPLOAD (OPTIONAL)

Attach a file. OmegaStorage handles upload, compression, and secure delivery. The path is stored in the listing but never exposed publicly.

04
EARN ON SALE — PLANNED

An 83%/17% seller/platform split is designed but not yet built — there is no buy step, no payment processing, and no revenue split anywhere in the platform today. Listings are visible and priced, not yet purchasable.
