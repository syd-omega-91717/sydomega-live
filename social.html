SOCIAL ARCHITECTURE

PLATFORM CONNECTIONS
Ten platforms supported: Instagram, X/Twitter, Facebook, YouTube, TikTok, LinkedIn, Telegram, Discord, Snapchat, Reddit. OAuth connections stored in social_connections table with RLS — each member sees only their own connections.
BROADCAST ENGINE
Sovereign broadcasts are stored in social_broadcasts with the selected network array and body. In production, a Supabase edge function routes each broadcast to the relevant platform API using stored OAuth tokens.
FEED SYSTEM
The feed aggregates stored broadcasts plus platform-specific activity seeds. Three views: ALL PLATFORMS (full history), MY BROADCASTS (user-authored content only), HOROSCOPE (astrological shares).
PRIVACY MODEL
Social connections and broadcasts are private to the authenticated user via RLS. No platform credentials are stored in plaintext — OAuth tokens are encrypted at rest. Platform usernames are stored as display handles only.
